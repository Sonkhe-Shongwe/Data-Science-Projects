# Data Science & Analytics Projects

A collection of projects exploring data analysis, statistical techniques and machine learning using Python. Each project includes source code, datasets, visualisations and findings.

## Projects

### 1. Unemployment Analysis with Python

Exploring unemployment trends across India and examining the impact of the COVID-19 pandemic on regional employment patterns.

**Technologies:** Python, Pandas, Matplotlib, Seaborn, Statistical Analysis

**Highlights:**
- Analysed 740 records across 28 regions, identifying unemployment trends and regional differences.
- Applied statistical tests including Pearson correlation, t-tests and ANOVA.
- Observed an increase in unemployment from 10.7% to 24.9% during lockdown.

### 2. Car Price Prediction with Machine Learning

Building and comparing regression models to estimate used-car selling prices based on vehicle characteristics.

**Technologies:** Python, Pandas, NumPy, Scikit-learn

**Highlights:**
- Prepared and explored 301 vehicle records, including data cleaning and categorical encoding.
- Evaluated five regression algorithms using R², RMSE and MAE.
- Extra Trees Regression achieved an R² of 0.92 and RMSE of 1.60.

### 3. Email Spam Detection with Machine Learning

Using natural language processing and classification algorithms to distinguish spam messages from legitimate emails.

**Technologies:** Python, Pandas, NLTK, Scikit-learn

**Highlights:**
- Performed text preprocessing and exploratory analysis on email data.
- Compared Logistic Regression, Random Forest, Extra Trees and Support Vector Machine models.
- Extra Trees achieved a reported classification accuracy of 97.78%.
